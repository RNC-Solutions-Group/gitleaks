## Assessment rules

- A linked PR is a **potential** fix, not a proven fix. Do not mark an issue resolved without reading diffs, running tests, and validating expected behavior independently.
- “No reference found” is an extraction limitation, not proof there is no available fix.
- Record assessment, rejection rationale, attempted integration, test evidence, and owner decision in [categories/](categories/README.md). Keep failed experiments visible instead of silently dropping candidates.
- CSV review fields `review_status` and `review_notes` start as `unreviewed` / blank. Changes to those fields must be reviewed and preserved across later snapshot refreshes.
