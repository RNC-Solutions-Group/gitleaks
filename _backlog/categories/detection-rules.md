## Decision gate

1. Reproduce against pinned `master`; confirm the shipped/default rule and generator agree. For new token formats, include positive, public/nonsecret, malformed, escaped and case/length boundary fixtures.
2. Compare overlapping PR regexes, token prefixes, keyword prefilters, entropy, rule IDs, generated config, and decode depth. A source-checked patch or authored test is not an implemented fix.
3. Preserve every contributor/PR; record an adoption only with the exact integrated upstream commit and RNC PR/commit. A competing open proposal is not a proven supersession or upstream closure.
4. Maintain this ownership ledger and [RNC exclusions](exclusions.md) without editing immutable `_backlog/data/` snapshots.
