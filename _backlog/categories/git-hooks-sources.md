## Cross-cutting implementation conclusions

1. **P0: never report a failed Git invocation as clean.** Treat #1981's #2080/#2292/#2339 and #2129's #2203 as **one engineering work package with distinct failure cases**, not four independent cherry-picks. Both stderr and process exit status matter; diagnostic warnings can coexist with valid output. DetectSource currently logs fragment errors and returns `nil`; the source must preserve the real failure until the CLI decides partial-scan/nonzero exit. Ensure no leaked child process or unconsumed stdout blocks Wait.
2. **P0: keep allowlist Boolean semantics.** [PR #2318](https://github.com/gitleaks/gitleaks/pull/2318) is **RNC rejected**, not selected. `detect.checkCommitOrPathAllowed` already evaluates global commit/path allowlists, including `AND`. The PR's new unconditional `continue` would discard a file if its commit matches but its required path does **not**, creating false negatives. The original inner-loop `continue` in `sources/git.go` is misleading/dead guard code; a later refactor may remove it after proving detector parity. See the exclusions ledger.
3. **P1: deterministic Git output before accuracy work.** Coordinate #2284 (`--no-color` for diff + log) with #2311 (pretty format); **also** pin date formatting and audit textconv from #1814. Keep #2301 merge diffs separately opt-out capable, with duplicate-finding policy and regression tests.
4. **Hooks demand two distinct products.** Default `git --pre-commit --staged` protects intended commit contents quickly, while `pre-commit run --files / --all-files` promises scanning named/checked files. #2319 fixes system-hook forwarding only; #1918's blanket `dir` swap risks an all-repo scan, ~90x slower in one upstream benchmark, and differences between working tree and index.
5. **No wholesale import of old PRs.** #1899 preserves a non-1-error fail-open hook, #1809 targets deleted files and changes trusted-host equality to unsafe substring matching, and #2128 does not prove the actual #2003 CSV complaint. Preserve upstream author credit, but require a corrected integrated design.
